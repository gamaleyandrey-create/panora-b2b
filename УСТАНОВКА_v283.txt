PANORA v283 — ЗАЩИТА СИНХРОНИЗАЦИИ

1. Загрузите 5 файлов приложения из архива в корень GitHub с заменой:
   admin.html
   index.html
   app.js
   cloud-sync.js
   sw.js

2. Дождитесь завершения публикации GitHub Pages.

3. Полностью закройте приложение на всех устройствах и откройте снова.
   Для первого запуска после обновления интернет должен быть включён.

Что изменено:
- ожидающие изменения больше не теряются после перезапуска;
- после восстановления связи локальные изменения отправляются до загрузки облачных данных;
- повторная синхронизация не создаёт повторных операций;
- очередь разделена для товаров, рецептур, ресторанов, плана, заказов и финансов;
- единый кэш приложения обновлён до v283.

SQL не требуется.

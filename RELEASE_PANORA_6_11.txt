Panora 6.11 — расшифровка потребности сырья

- Колонка «Нужно» на Складе сырья стала кликабельной.
- Для каждого ингредиента открывается точная расшифровка:
  дата выпечки → источник → вид хлеба → количество хлеба → количество ингредиента.
- Источник отмечается явно:
  «Заказы партнёров» — если на дату есть реальные заказы;
  «План выпечки» — только если на конкретную дату заказов нет.
- Исправлена логика будущей потребности: fallback на план теперь выполняется отдельно для каждой даты,
  а не только когда заказов нет вообще во всём выбранном периоде.
- Для полуфабрикатов расшифровка учитывает физический остаток полуфабриката.
  В исходное сырьё попадает только та часть, которую действительно нужно приготовить,
  с отображением полуфабриката и процента выхода.
- В окне расшифровки показаны: всего нужно, текущий остаток, дефицит.
- Из расшифровки можно сразу открыть «Закупку» или создать «Приход».
- PWA/cache: 6110.
- SQL/Supabase: изменений нет.

PANORA v282 — СТАБИЛЬНЫЙ ЗАПУСК И ОФЛАЙН-РЕЗЕРВ

Что исправлено:
- все локальные стили и скрипты подключаются с единым номером v282;
- при установке заранее сохраняются основные файлы приложения;
- страницы ресторана и пекарни могут открыться из кэша при временном отсутствии сети;
- повреждённые локальные данные ресторанов больше не останавливают запуск кабинета пекарни.

Установка:
1. Загрузите 4 файла приложения из архива в корень GitHub с заменой.
2. Дождитесь завершения публикации сайта.
3. Полностью закройте приложение на всех устройствах и откройте снова.
4. Для первой загрузки после обновления интернет должен быть включён.

SQL не требуется.

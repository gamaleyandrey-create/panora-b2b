Panora 6.06 — склад сырья + проверка PWA-обновления

СКЛАД СЫРЬЯ
- Добавлен отдельный раздел «Склад сырья».
- Остатки ведутся по ингредиентам из действующих рецептур, включая исходное сырьё полуфабрикатов.
- Старые остатки из «Закупки» один раз мигрируют в начальные остатки склада сырья.
- Колонка «Остаток» в Закупке теперь использует фактический ledger склада сырья.
- Изменение остатка прямо в Закупке создаёт операцию «Инвентаризация».
- Операции: Приход закупки, Инвентаризация, Корректировка +, Списание / брак, Корректировка −.
- История: последние 30 дней / архив.
- Прошедшие дни выпечки автоматически списывают сырьё по заказам и текущим рецептурам.
- Текущий день не списывается заранее.
- При отсутствии заказов на дату используется существующий fallback по плану.
- Для полуфабриката сначала расходуется его фактический остаток; дефицит переводится в расход исходного сырья через процент выхода.
- Склад показывает остаток, потребность на активные даты, остаток после будущей выпечки, цену, стоимость и дефицит.
- Автоматические движения не удаляются; ручные можно удалить.
- Движения склада сырья в 6.06 хранятся на текущем устройстве. SQL/Supabase не требуется.

КНОПКА «ОБНОВИТЬ»
- PWA build = 6060.
- При нажатии кнопка показывает «Обновляем…».
- После SKIP_WAITING выполняется reload на activation/controllerchange.
- Для Safari/iOS добавлен резервный reload через 2,2 секунды.
- После загрузки временный build-параметр удаляется из URL.
- Reload-loop исключён.

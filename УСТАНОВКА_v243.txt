PANORA v243 — АТОМАРНАЯ ОТГРУЗКА

1. Откройте Supabase → SQL Editor → New query.
2. Откройте файл supabase-v243-atomic-shipment.sql обычным текстовым редактором.
3. Скопируйте ВЕСЬ SQL-код из файла в SQL Editor.
   Не вставляйте в редактор только название файла.
4. Нажмите Run. Правильный результат: Success.
5. Загрузите в корень репозитория GitHub четыре файла:
   admin.html
   cloud-sync.js
   commerce.js
   sw.js
6. Сделайте Commit changes и дождитесь зелёного развертывания GitHub Pages.
7. На устройстве закройте Panora полностью и откройте снова.

Что исправлено:
- отгрузка, фактическое количество, накладная, оплата и статус сохраняются
  одной транзакцией;
- если облако отклоняет операцию, заказ остаётся подтверждённым, а окно
  отгрузки остаётся открытым;
- повторное нажатие не создаёт вторую накладную;
- старые отгруженные заказы без накладной восстанавливаются автоматически;
- исправляется последовательность номеров накладных;
- добавляются недостающие поля для офлайн-подтверждения.

Проверка:
- откройте подтверждённый заказ;
- нажмите «Отгрузить и создать накладную»;
- окно должно закрыться;
- статус должен стать «Отгружен»;
- накладная должна появиться у пекарни и соответствующего ресторана.

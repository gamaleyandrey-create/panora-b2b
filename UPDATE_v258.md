# Обновление Panora v258

Что исправлено:

- ресторан получает только описание товара и свою индивидуальную цену;
- рецептуры, закупочные цены, себестоимость, маржа и базовая цена закрыты;
- изменения встроенных карточек больше не сбрасываются обновлением;
- новый вид хлеба по умолчанию создаётся с весом 750 г;
- обновлён кэш приложения.

## Установка

1. Загрузите изменённые файлы приложения в корень репозитория GitHub.
2. В Supabase откройте **SQL Editor → New query**.
3. Откройте файл `supabase-v258-private-product-data.sql`, скопируйте **весь его текст** в редактор и нажмите **Run**.
4. Не вводите в SQL Editor одно имя файла — Supabase выполняет только содержимое SQL.
5. Дождитесь зелёного развёртывания GitHub Pages и обновите приложение.

После обновления войдите как ресторан и проверьте каталог: должны отображаться карточки и цены этого ресторана, но не базовая цена и не рецептура.

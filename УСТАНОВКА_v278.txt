PANORA v278 — ТЕХНОЛОГИЧЕСКИЕ КАРТЫ

1. В Supabase откройте SQL Editor.
2. Выполните файл supabase-v278-tech-cards.sql один раз.
3. Загрузите остальные 5 файлов из архива в корень GitHub с заменой:
   admin.html
   cloud-sync.js
   recipe-percent.js
   recipe-percent.css
   sw.js
4. Полностью закройте приложение и откройте снова.

В разделе «Рецептуры» у каждого товара появится технологическая карта.
Кнопка «Печать / PDF» открывает чистую печатную форму. В системном окне
печати выберите «Сохранить как PDF», если нужен PDF-файл.

# Panora v244 — атомарные оплаты

## 1. Обновите Supabase

1. Откройте Supabase → **SQL Editor** → **New query**.
2. Откройте файл `supabase-v244-atomic-payment.sql` на компьютере.
3. Скопируйте **весь текст из файла** в SQL Editor.
4. Нажмите **Run**. Должно появиться сообщение об успешном выполнении.

Не вводите в SQL Editor только имя файла — Supabase выполняет SQL-код, а не
открывает файлы с компьютера.

## 2. Обновите файлы приложения

Загрузите с заменой:

- `cloud-sync.js`
- `commerce.js`
- `account-detail.js`
- `admin.html`
- `sw.js`

Дождитесь зелёного статуса GitHub Pages.

## 3. Обновите приложение на устройствах

- В браузере обновите страницу два раза.
- Если Panora установлена на домашний экран, полностью закройте её и откройте
  снова.

## 4. Проверка

1. На устройстве A запишите оплату — она должна появиться со статусом ожидания.
2. На устройстве B откройте того же ресторана — операция должна быть видна.
3. На устройстве B подтвердите получение.
4. Проверьте на обоих устройствах: задолженность и сумма подтверждённых оплат
   должны совпадать.

Теперь интерфейс не создаёт локальную оплату до ответа Supabase. При ошибке
операция не попадёт в баланс и будет показано понятное сообщение.

PANORA v248 — журнал операций и восстановление отгрузок

1. Откройте Supabase → SQL Editor.
2. Скопируйте всё содержимое файла supabase-v248-operation-journal.sql.
3. Выполните запрос один раз. В результате не должно быть красной ошибки.
4. В корень репозитория panora-b2b загрузите с заменой:
   - admin.html
   - audit-log.js
   - cloud-sync.js
   - sw.js
5. Дождитесь зелёного развертывания GitHub Pages.
6. Откройте приложение и один раз обновите страницу.

Что изменено:
- действия с заказами, накладными и оплатами сохраняются в Supabase;
- история не исчезает после очистки браузера или смены устройства;
- если отгрузка записалась в облако, но ответ потерялся из-за связи,
  приложение находит созданную накладную и восстанавливает результат;
- локальный журнал и журнал Supabase показываются вместе.

Важно:
- ZIP-файл GitHub сам не распаковывает. Сначала распакуйте архив на компьютере,
  затем загрузите перечисленные файлы в корень репозитория.
- SQL-файл не загружается в приложение: его нужно выполнить в Supabase SQL Editor.

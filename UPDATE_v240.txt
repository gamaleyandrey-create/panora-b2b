PANORA v240 — восстановление накладных

1. Загрузите файлы cloud-sync.js, admin.html, app.js и sw.js в корень репозитория.
2. В Supabase → SQL Editor выполните один раз файл:
   supabase-v240-repair-invoices.sql
3. Дождитесь зелёного GitHub Pages deployment.
4. Откройте экран пекарни и обновите страницу.
5. Затем откройте кабинет ресторана → Накладные.

Что исправлено:
- отгруженный заказ без строки накладной автоматически получает накладную;
- проверка выполняется по данным Supabase, а не только по памяти браузера;
- одна старая локальная запись больше не блокирует восстановление остальных накладных.
